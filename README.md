# ⚡ 꼬마 전기 실험실

6세 어린이를 위한 전기회로 실험 웹 게임입니다. 건전지·전구·스위치를 마우스로 끌어다 전선으로 이으면,
실제 회로 계산(옴의 법칙 + 키르히호프 법칙)으로 전류가 얼마나 흐르는지 숫자, 수식, 움직이는 점, 전구 밝기로 보여줍니다.

## 바로 하기

👉 **https://hellohanaworld.github.io/baby_electric_circuit/** (크롬 권장)

`main` 브랜치에 올리면 GitHub Actions가 `public/` 폴더를 GitHub Pages로 자동 배포합니다.

## 내 PC에서 실행

```bash
node server.js            # http://localhost:8080
PORT=3000 node server.js  # 포트 바꾸기 (PowerShell: $env:PORT=3000; node server.js)
```

Node.js 16 이상이면 되고, 설치할 패키지는 없습니다. `public/` 폴더는 정적 파일이라 Netlify, GitHub Pages, Vercel,
nginx 같은 곳에 그대로 올려도 됩니다.

Docker:

```bash
docker build -t kkoma-circuit .
docker run -p 8080:8080 kkoma-circuit
```

## 구성

| 파일 | 역할 |
|---|---|
| `server.js` | 의존성 없는 정적 파일 서버 (`/health` 상태 확인용) |
| `public/js/sim.js` | 회로 계산 엔진 (마디 해석법), 직렬/병렬 판별, 아이 눈높이 수식 생성 |
| `public/js/missions.js` | 주제 10개 + 자유 실험실 (목표, 힌트, 성공 설명) |
| `public/js/stages.js` | 주제마다 스테이지 10개 만들기 (미리 놓을 재료·전선) |
| `public/js/app.js` | 화면 그리기, 드래그, 전류 애니메이션, 효과음, 한국어 읽어주기 |

## 미션 (주제 10개 × 스테이지 10개 + 자유 실험실)

주제마다 1-1 ~ 1-10 처럼 스테이지가 10개 있고, 아주 조금씩 어려워집니다.

| 스테이지 | 미리 놓인 것 | 아이가 할 일 |
|---|---|---|
| X-1 | 재료 + 전선 (하나만 빠짐, 점선으로 안내) | 전선 1개 잇기 |
| X-2, X-3 | 전선 하나만 빠짐 (모양이 바뀜) | 전선 1개 잇기 |
| X-4, X-5 | 전선 2개 빠짐 | 전선 2개 잇기 |
| X-6 | 재료만 | 전선 모두 잇기 |
| X-7 | 재료 하나가 재료 상자에 | 꺼내서 잇기 |
| X-8 | 전지만 | 나머지 꺼내서 만들기 |
| X-9 | 빈 판 | 혼자 다 만들기 |
| X-10 | 빈 판 + 필요 없는 재료 | 알맞은 재료 골라서 만들기 |

주제 (1~5 전구 💡, 6~10 선풍기 🌀 — 같은 순서를 두 번 배워요):

| 전구 | 선풍기 | 배우는 것 | 레이아웃 A → B |
|---|---|---|---|
| 1 불을 켜요 | 6 선풍기 돌려요 | 닫힌 회로 (0.5A) | 전지 1 + 부품 1 |
| 2 스위치 딸깍 | 7 선풍기 스위치 | 스위치로 켜고 끄기 | 전지 1 + 부품 1 + 스위치 1 |
| 3 더 밝게! | 8 더 빠르게! | 전지 직렬 3V (1A) | 전지 2 → + 스위치 |
| 4 전구 기차 | 9 선풍기 기차 | 부품 직렬 (0.25A, 전압을 반씩) | 부품 2 → + 스위치 |
| 5 전구 사다리 | 10 선풍기 사다리 | 부품 병렬 (전압을 통째로) | 부품 2 → 전지 2 + 갈래마다 스위치 |

깜깜하게(🌙) 버튼을 누르면 불빛 크기(∝ √밝기)로 직렬·병렬 밝기를 비교할 수 있습니다.

스테이지 배치는 `public/js/stages.js`에 있습니다.

진행 상황은 브라우저 localStorage에 저장됩니다.
